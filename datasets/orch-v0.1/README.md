# orch-v0.1 — orchestrator-track task set

27 Harbor tasks: 4 families × their sizes × seeds 1–3. Generated by
`tools/orch_generate.py`; `tests/test_orch_tasks.py` fails if this directory
drifts from the generators, so regenerate rather than edit:

```bash
python tools/orch_generate.py --out datasets/orch-v0.1
```

| family | size | delegation label | seeds | task ids |
|---|---|---|---|---|
| W | 6 support tickets to sweep | `optional` | 1, 2, 3 | `orch-w-n6-s*` |
| W | 24 support tickets to sweep | `delegate` | 1, 2, 3 | `orch-w-n24-s*` |
| W | 72 support tickets to sweep | `delegate` | 1, 2, 3 | `orch-w-n72-s*` |
| P | 3 services to diagnose | `optional` | 1, 2, 3 | `orch-p-n3-s*` |
| P | 10 services to diagnose | `delegate` | 1, 2, 3 | `orch-p-n10-s*` |
| P | 20 services to diagnose | `delegate` | 1, 2, 3 | `orch-p-n20-s*` |
| C | 4 modules to change | `solo` | 1, 2, 3 | `orch-c-n4-s*` |
| C | 7 modules to change | `solo` | 1, 2, 3 | `orch-c-n7-s*` |
| S | 1 single-file bug fix | `solo` | 1, 2, 3 | `orch-s-n1-s*` |

`delegate` means a solo agent under the reference limits (32k context, 40 steps)
hits a wall and delegating should pay. `optional` means either policy can win.
`solo` means delegating costs more than it returns. See `../../ORCHESTRATOR.md`.

Each task directory is standard Harbor:

```
task.toml          metadata: family, size, seed, delegation_label, work_items, limits
instruction.md     the only thing the agent is told
environment/       Dockerfile + workspace/ (+ opt/svcctl for P)
tests/             verify.py + ground_truth.json (+ hidden_checks.py for C and S)
solution/solve.sh  oracle; must score 1.0
```

Run it:

```bash
harbor run -p datasets/orch-v0.1 -a oracle                                   # sanity: all 1.0
harbor run -p datasets/orch-v0.1 -a claude-code -m <model> --ak disallowed_tools=Agent,Task -o jobs/solo
harbor run -p datasets/orch-v0.1 -a claude-code -m <model> -o jobs/delegate
python tools/orch_collect.py jobs/solo jobs/delegate
```

`reward.json` carries `reward` in [0, 1] plus sub-scores. The ground truth is
only in `tests/`, which Harbor uploads after the agent finishes.
